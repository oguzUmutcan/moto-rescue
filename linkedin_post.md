🚀 Excited to share my latest full-stack mobile project: MotoRescue! 🏍️

MotoRescue is a role-based mobile assistance app designed to instantly connect passengers in need of transport with
nearby motorcycle riders.

Built with scalability, security, and real-time interaction in mind, here are the core features that power the app:
🔹 Role-Based Matching: Dedicated interfaces and logic for 'Passengers' and 'Bikers'.
🔹 Real-Time Tracking & Routing: Integrated with Google Maps, Places, and Routes APIs for live tracking and
accurate distance calculation.
🔹 Solid Architecture: Built with React Native (Expo) on the frontend, powered by a robust Java Spring Boot
backend.
🔹 Secure Auth & State Management: Firebase Authentication handles identity, while the backend acts as the absolute
authority using strict state machines and Firestore transactions to prevent race conditions.
🔹 Gamification: Built-in XP, leveling, and badge systems to reward helpful riders!

Building this taught me a lot about handling concurrent requests, proxying APIs securely, and keeping complex
mobile states perfectly synced with a backend.
